# 📞 Sipulse - Notificador e Auto-Atendimento

Este é um script para a extensão **Tampermonkey** que melhora a experiência de uso do sistema de telefonia Sipulse.

## ✨ O que ele faz?
1. **Notificações no Desktop:** Avisa no Windows/Mac sempre que uma ligação entra, mesmo se você estiver trabalhando em outra aba ou com o navegador minimizado.
2. **Atendimento Rápido:** Ao clicar na notificação, ele automaticamente traz o sistema para a frente e **atende a chamada virtualmente**, clicando no botão verde por você.

## 🚀 Como instalar (Para a equipe)

1. Instale a extensão [Tampermonkey](https://tampermonkey.net/) no seu navegador (Chrome, Edge ou Firefox).
2. Clique **[NESTE LINK AQUI](https://github.com/Samuelluiz280/SIPulse/raw/main/sipulse-notificador.user.js)** para instalar o script.
3. O Tampermonkey vai abrir uma tela preta perguntando se deseja instalar. Clique no botão **Instalar**.
4. Entre na aba do Sipulse e atualize a página (`F5`). O navegador vai pedir permissão para mostrar notificações, clique em **Permitir**. 

Pronto! Agora é só não deixar a aba do Sipulse ser fechada.
